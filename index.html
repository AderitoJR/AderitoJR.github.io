DealPoint

ERP e POS para PMEs moçambicanas

Sistema comercial completo para lojas, restaurantes, farmácias, escolas, hotéis, microcrédito e mais de uma dezena de outros negócios. Cada cliente ativa só os módulos de que precisa.

DashboardIndicadores de stock, vendas, dívidas de clientes, lucro líquido e saúde do negócio.

  • Offline-first

    Funciona sem internet em SQLite e sincroniza com PostgreSQL quando há ligação. Suporta vários caixas, vários postos e partilha em rede local.

  • Segurança

    Criptografia AES-256-GCM dos dados sensíveis, perfis de utilizador, registo de auditoria de ações, backups agendados e chave de base de dados no Credential Manager do Windows.

  • Hardware real

    Impressão térmica ESC/POS, leitor de códigos e PDFs de recibos, relatórios, receitas e guias de transporte.

  • Regras locais

    Moeda múltipla com câmbio, IVA, registo de controlados na farmácia, campos SEF na hospedagem, avaliação escolar segundo o Diploma Ministerial 59/2015, IMI no imobiliário.

  • Integração

    API REST de leitura para o telemóvel (stock, finanças e notificações) e fila de sincronização para servidor remoto.

  • Distribuição

    Instalador MSI nativo, painel técnico exclusivo da Alltech para licença, diagnóstico e recuperação de acessos.

    Operação financeira, fila de saques com dupla proteção, faturas e inadimplência, cupões de desconto e tarifa dinâmica.

Utilitário Windows

VoidTrace09

Ferramenta de HelpDesk para técnicos

Reúne num único programa os diagnósticos que um técnico faz todos os dias, com acesso protegido e interface gráfica, distribuído como um .exe.

  • Hardware: tipo de RAM (DDR3, DDR4, DDR5), memória de vídeo dedicada, TRIM, virtualização, plano de energia, Secure Boot e TPM, com pontuação de preparação para jogos.
  • Discos: diagnóstico de “porque é que o disco não liberta espaço”, com remoção segura de Windows.old.
  • Falhas: histórico real de BSOD, diagnóstico físico de pen USB, gestor de serviços e atualizações.
  • Sem winget instalado, avisa e abre a ligação oficial, em vez de instalar sozinho.
